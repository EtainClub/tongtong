# 청사진 사용자 확인 — 학부생 5명 (B4 관문)

청사진 설계 부록 A-11, 로드맵 1.2의 3번. B4(AI)로 가기 전에 **청사진이 쓰이는지, 읽히는지**를 사람에게서 본다. 측정(`pnpm metrics`의 청사진 표, 4주)과 함께 B4를 열지 정하는 근거다.

## 누구를

- 학부생 5명 안팎. 박사 진학을 생각하는 이공계 2–3명, 창업에 관심 있는 2–3명.
- 학년이 섞이게(1·2학년이 있어야 "출발 달"을 미래로 고르는 경우를 본다).
- 통통을 처음 쓰는 사람. 만든 사람이 옆에서 설명하지 않는다.

## 어떻게

- 각자 자기 휴대폰으로 https://tt.jamtong.kr (390px 안팎 화면). 20–30분.
- 소리 내어 생각하기: "지금 무엇을 보고, 무엇을 하려는지 말해 주세요."
- 진행자는 과제만 읽고, 막혀도 3분은 돕지 않는다. 막힌 곳이 결과다.
- 기록은 이 문서의 표에 사람마다 한 줄씩. 이름·학교·연락처는 적지 않는다(학년·관심만).
- 판단 기록·청사진 내용은 그 사람 기기에 남는다 — 끝나면 "내 기록 → 청사진 지우기"를 할지 본인이 정하게 한다.

## 과제

| # | 과제 (진행자가 읽는 말) | 보는 것 |
|---|---|---|
| 1 | "통통을 처음 열었어요. 시작해 보세요." | 온보딩을 넘기는가 |
| 2 | "졸업 뒤 박사까지 가는 길(또는 창업)을 계획해 보고 싶어요. 여기서 해 보세요." | 하단 탭 **청사진**을 찾는가, 견본을 고르는가 |
| 3 | 만들기 2단계에서 아무 말 없이 둔다 | **출발 달**("학부 3학년은 언제인가요?")을 이해하는가, 자기 학년에 맞춰 미래 달을 고르는가 |
| 4 | "저장한 청사진에서 2028년 하반기에 무엇이 있는지 말해 주세요." | 반기 띠·"계속:" 줄을 읽는가 |
| 5 | "'확정'·'예상'·'미정'(또는 '예상 · 시기 확인')이 붙은 칸을 하나씩 골라, 각각 무슨 뜻인지 말해 주세요." | 확실성 라벨(확정·예상·미정·시기 확인)을 어떻게 읽는가. 확정으로 믿는가 |
| 6 | "취업 후 상환 학자금대출 칸을 눌러 보세요. 이건 받는 돈인가요?" | "갚아야 해요"를 알아보는가 |
| 7 | "위쪽 '점검할 것'에서 하나를 처리해 보세요." | 반영·이대로·닫기의 차이를 아는가, 처리 뒤 REV가 오른 것을 알아채는가 |
| 8 | "방금 바꾼 게 기록에 남았는지 확인해 보세요." | REV 기록을 찾는가 |
| 9 | "피드에서 카드 하나를 끝까지 보고, 그 정책을 청사진에 넣어 보세요." | 끝 화면의 "청사진에 넣기"를 찾는가, 두 번 탭 안에 넣는가 |
| 10 | (끝나고) "다음 달에 다시 열어 볼 것 같나요? 무엇이 있으면 열겠어요?" | 다시 올 이유 — AI 초안(B4)·알림(B5)을 원하는지, 견본·정책이 더 필요한지 |

## 판단 기준 (B4를 열지)

- **견본·항목부터** (B4 미룸): 5명 중 3명 이상이 "정책이 너무 적다", "내 길(취업·다른 전공)이 없다"고 하거나, 측정에서 "만든 뒤 30일 안에 다시 고친 비율"이 낮으면 — 청사진 설계 9.3(견본·항목 늘리기)을 먼저.
- **화면부터**: 3·5·7에서 3명 이상이 막히면 그 화면을 먼저 고친다(출발 달 문구, 확실성 설명, 점검 문구).
- **B4로**: 위 둘이 아니고, 10에서 "처음부터 짜 주면 좋겠다"·"내 상황에 맞게 물어보고 싶다"가 나오면.

결과는 청사진 설계 B3 상태 아래 "B3에서 B4로 가기 전 확인"에 요약해 적는다.
