| `income` 도시근로자 월평균 소득 100% 이하, 1인 120%·2인 110% | 맞음 | "해당세대(세대원은 본인 기준) 월평균 소득 합계가 전년도 도시근로자 가구원수별 가구당 월평균 소득의 100% 이하", 1인가구 120%, 2인가구 110% (LH) |
| `asset` 총자산·자동차가액 기준이 따로 있다 | 맞음 — 금액은 뺐다 | LH "총자산 25,100만원 이하", "자동차 4,542만원 이하". 마이홈 "총자산 29,900만원, 자동차 3,683만원"(2023년 기준 표기). **두 곳 금액이 달라** 금액은 claim에 넣지 않았다 |
| `newcomer` 사회초년생 구분, 소득 있는 업무 종사기간 5년 이내 | 맞음 | 사회초년생은 "소득이 있는 업무 종사 기간이 총 5년 이내" (LH) |
| `rent` 시중 시세의 60~80% | 맞음 | "공급대상자별 시중시세의 60~80%" (마이홈) |
| `duration` 2년 단위 계약·갱신, 대학생·청년 최대 6년 | 맞음 | "2년단위로 계약체결", "당해 임대차기간 종료시 입주자격 재확인 후 갱신계약 체결", "대학생·청년·산업단지근로자는 최대 6년" (마이홈) |
| `planning.age` 19–39 | `target` | |
| `planning.durationMonths` 72 | `duration`의 "최대 6년" | |

확인할 것:
- 자산 기준 금액 — 지금 모집공고의 금액을 넣으려면 최근 행복주택 모집공고 원문 하나를 출처로 더한다.
- 모집 일정 — 단지별 공고라 `recurrence`를 두지 않았다. 청사진에서는 "미정"으로 그려진다.
- 청년 버팀목과의 관계 — 버팀목 항목의 `no-duplicate`에 "공공임대주택에 살고 있으면 원칙적으로 받을 수 없다"가 있다. 행복주택 쪽 원문에는 같은 문장이 없어 `exclusiveWith`(양쪽에 근거 claim이 있어야 한다)에 적지 않았다.

## 청년주택드림청약통장 — 비판·한계 후보 1

출처: [뉴스1 2026-01-19 「지난해 청년주택드림대출 서울 실행 0건…"구조적 한계 존재"」](https://www.news1.kr/realestate/general/6043215) (김동규 기자)

규칙(공공기관 자료나 그것을 인용한 보도) — **맞음**. 수치는 "국회 국토교통위원회 소속 문진석 더불어민주당 의원이 국토교통부로부터 제출받은 자료"다.

본문에서 찾은 문장:
- "청년주택드림대출은 지난해 4월 출시 이후 11월까지 8개월간 전국에서 총 13건, 32억 원이 실행됐다."
- "서울과 부산, 대구, 인천, 광주, 대전에서는 실행 건수와 금액 모두 '0'으로 집계됐다."
- "같은 기간 전국에서 185건, 422억 원 규모의 대출 신청이 접수된"
- "2024년 2월 출시된 청년주택드림청약통장에 1년 이상 가입하고 1000만 원 이상을 납입한 청약자가 대상"
- 국토부 관계자: "대출 대상자로 심사가 완료됐지만 아직 실행 시점이 도래하지 않아 대기 중인 사례도 있다", "향후 실행률은 점차 늘어날 것"
- 분양가 6억 원·85㎡ 조건이 서울·수도권과 맞지 않는다는 것은 "일각에서는 … 지적" — 누가 했는지 없어서 **문장에 넣지 않는다**.

넣을 문장(제안) — `counterpoints`:

```ts
{
  id: "cp-loan-rarely-executed",
  text: "청약통장 가입자가 당첨 뒤 쓰는 청년주택드림대출은 2025년 4~11월 전국에서 13건(32억 원)이 실행돼, 같은 기간 신청 185건(422억 원)보다 크게 적었고 서울에서는 한 건도 없었다. 국토교통부는 심사를 마치고 입주를 기다리는 경우가 있어 실행이 점차 늘 것이라고 설명했다.",
  assertionType: "CLAIM",
  assertedBy: "국토교통부 제출 자료(문진석 의원실), 뉴스1 보도(2026-01-19)",
  verified: true,
  sourceIds: ["news1-2026-01-19"],
}
```

카드 공개에는 정책 평가 이유(`reasonOptions`) 3개 이상도 필요하다 — 지금 0개. 초안:

| id | 문장 | 근거 claim |
|---|---|---|
| `rate-tax-helps` | 연 4.5% 금리와 비과세가 도움이 된다 | `rate`, `tax` |
| `start-early` | 무주택 청년이 일찍 청약을 준비할 수 있다 | `age`, `no-house` |
| `income-proof` | 소득이 증빙돼야 해서 소득 없는 청년은 가입할 수 없다 | `income` |
| `loan-rarely-used` | 이어지는 대출이 실제로는 거의 실행되지 않았다 | `cp-loan-rarely-executed` |

카드 파일 머리 주석은 "청년주택드림대출은 다른 정책이고 대상 연령도 다르다 — 이 카드에서 뺐다"고 적고 있다. 이 비판은 대출을 **소개**하지 않고 청약통장의 한계로만 쓴다. 대출 조건(분양가 80%, 40년, 2.2%)은 문장에 넣지 않았다.
