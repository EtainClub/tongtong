좋아. 이제 **청년 트랙의 실제 초기 콘텐츠 10개**를 통통에 바로 넣을 수 있는 형태로 잡아보자.

먼저 모든 카드의 공통 구조는 이렇게 통일하는 게 좋다.

`숏츠 → 첫 판단 → 게임 → 사실 공개 → 원자료 → AI에게 따져보기 → 최종 판단 → 관심카드 저장`

그리고 `첫 판단`과 `최종 판단`은 동일한 5단계 척도를 사용한다.

`매우 신뢰 / 대체로 신뢰 / 모르겠음 / 다소 의심 / 매우 의심`

이 두 값을 모두 저장하면 **자료를 보기 전과 후의 판단 변화**가 생긴다.
