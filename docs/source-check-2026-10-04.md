# 초안 원문 대조 준비 (2026-10-04)

`pnpm review`의 검증 전 claim 35개(정책 항목 8개 31개, 경로 견본 2개 4개)를 각 claim의 출처 원문과 대조한 기록이다.
대조는 AI(Claude)가 출처 페이지를 읽어 한 것이다 — **`verified: true`로 바꾸는 것은 편집자가 원문을 직접 확인한 뒤**다(청사진 설계 9.3). 아래 "맞음"은 "원문에서 같은 말을 찾았다"는 뜻이고, 그 문장을 함께 적었다.

| 판정 | 뜻 |
|---|---|
| 맞음 | 출처 원문에 같은 내용이 있다 |
| **고칠 것** | 출처와 다르다 — 문장을 고친 뒤 대조 |
| 출처에 없음 | 내용은 맞을 수 있지만 적힌 출처에서 찾지 못했다 — 출처를 바꾸거나 claim을 뺀다 |

## 요약

- 맞음 **32개**, 고칠 것 **1개**, 출처에 없음 **1개**, 표기 확인 **1개** — 모두 취업 후 상환 학자금대출이다.
- 나머지 정책 7개(국가장학금·연구생활장려금·BK21·학생 창업유망팀·예비창업패키지·청년창업사관학교·세액감면)와 견본 2개의 claim은 출처와 맞았다. 편집자 확인이 끝나면 바로 공개할 수 있다.
- `planning` 값(사업 종료 달, 지원 기간, 회차 날짜)도 claim과 맞는다.

**반영 (같은 날)** — `grad`를 "대학원생은 대출 신청일 기준 만 40세 이하여야 한다. 등록금 대출은 소득구간과 관계없고, 생활비 대출은 학자금 지원구간 6구간 이하여야 한다."로 고쳤다. `tuition`은 빼고 `repay`("등록금과 생활비를 빌려주고, 취업 등으로 소득이 생긴 때부터 소득 수준에 따라 원금과 이자를 갚는 대출이다.")로 바꿨다 — 같은 페이지의 "취업 등 소득이 발생한 시점부터 소득수준에 따라 원리금을 상환하는 대출". `planning.repayable`은 `repay`를 가리킨다. 둘 다 아직 `verified: false`다.

## 공개 순서 제안

1. 위 표를 보며 원문을 확인하고 `verified: true`, 항목 `reviewedAt`, `publishStatus: "published"`. 학자금대출은 `grad`·`tuition`을 고친 뒤.
2. **견본을 공개하려면 칸의 항목이 모두 공개여야 한다.** `phd-stem`은 `exam-fee-support`(국가기술자격 응시료)도 공개 항목이어야 하고, `startup-in-college`는 위 정책 4개와 이미 공개된 항목들이다.
3. `exam-fee-support`·`youth-housing-dream-account`·`youth-challenge`는 **항목의 claim이 이미 모두 검증**됐다. 막혀 있는 것은 **카드**의 비판·한계(카드 공개 조건)뿐이고, 항목 공개에는 비판·한계가 필요 없다(청사진 설계 2.2 규칙 6). 항목만 먼저 공개하면 정책 페이지와 청사진에 쓸 수 있고, 카드는 비판·한계를 찾은 뒤 따로 공개한다.
4. 견본 하나가 공개되면 피드 머리·내 기록의 청사진 진입점이 열린다(`PLAN_ENTRY_OPEN`).
5. `pnpm check && pnpm build` → 배포 (README "배포").

## 대조하지 않은 것

- 이미 검증된 항목(공개 카드 7장, 위 3개)은 다시 보지 않았다.
- 출처 페이지가 나중에 바뀌었을 수 있다 — 2026-10-04에 읽은 내용이다.
