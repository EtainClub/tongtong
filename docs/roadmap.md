## 4. UI/UX 구현 명세

공통 규칙: 잼통 디자인 시스템. 무채색 UI, 데이터에만 색(navy = 지금, burgundy = 처음·점선, pending = 확인 전). 누르는 것은 pill, 숫자만 mono, `word-break: keep-all`, 모션은 `cubic-bezier(0.16, 1, 0.3, 1)`이고 `prefers-reduced-motion`에서 끈다. 모든 조작은 버튼으로도 된다. 기준 화면은 390 × 844.

### 4.1 피드 `/` (M4)

```
통통                          [내 기록]

  ┌───────────────────────────┐╮  ← 다음 카드가 4px 아래·2% 작게 비친다
  │ 주거 · 약 1분              ││
  │                           ││
  │ 월세 최대 480만 원을       ││
  │ 지원받을 수 있다?          ││
  │                           ││
  │ [2026년 신청 마감]         ││
  └───────────────────────────┘╯

 [관심 없음]   [나중에]   [ 보기 ]
            남은 카드 7
```

- **스와이프**: 수평 드래그만 잡는다(`touch-action: pan-y` — 세로 스크롤은 그대로). 카드가 손가락을 따라가고 기울기는 최대 6°. 폭의 30% 또는 속도 0.5px/ms를 넘기면 확정. ← `관심 없음`, → `보기`. 확정 전 가장자리에 행동 이름이 떠오른다("관심 없음" / "보기"). 놓으면 제자리로 스프링.
- 드래그 중에는 전환을 끄고(잼통 모션 규칙) 놓을 때 250ms로 나간다.
- 키보드: ← / → 가 같은 동작. 스크린 리더는 버튼만 쓴다(드래그 영역은 `aria-hidden`이 아니라 버튼과 같은 이름).
- `관심 없음`은 의견이 아니다 — 피드 아래 한 줄로 "관심 없음은 어떤 집계에도 들어가지 않아요"를 첫 사용 때만 보여 준다.
- **Hook 카드 정보**: 위쪽에 `주제 · 약 N분`(sans, smoke). 신청 상태 배지는 지금처럼 아래쪽.
- **빈 중앙**: 훅 아래에 숏츠 첫 줄을 흐리게(smoke) 한 줄 — 들어갈 이유를 준다.
- **prefetch**: 다음 두 카드의 `/card/{id}` 링크를 미리 불러온다.

### 4.2 카드 흐름 `/card/{id}` (M4·M5)

단계 표시 `01 / 06`은 머리에만 둔다. 단계 안의 진행은 막대(숏츠)나 라벨 붙은 수("조건 1 / 4")로 — 숫자만 둘이 되지 않게.

**숏츠** — 지금 그대로(글자 씬, 한 줄씩, 한 번에 보기). M9에서 `video`가 있으면 9:16 영상, 자막 켜짐 고정, 자동 재생 없음.

**게임 → "통!"** (M4)

- 정답을 고르면 선택지가 제자리에서 정답·오답 상태로 바뀌고(색 없이 — 정답은 ink 채움, 내 오답은 취소선), 결과 문장이 올라온다.
- "통!"은 결과 문장 앞의 짧은 튀어오름: scale 0.9 → 1.04 → 1, 320ms. 한 번만. 모션이 꺼져 있으면 바로 최종 상태.
- 금액 맞히기: 공개 숫자는 `KeyNumber`(mono, 큰 수) + 근거 칩. 내 예상과 실제를 같은 막대 위 두 점으로(데이터이므로 navy = 실제, burgundy 점선 = 내 예상).

**새 게임 유형** (M5) — 모두 버튼으로 끝낼 수 있어야 한다.

| 유형 | 조작 | 공개 |
|---|---|---|
| slider | 범위 슬라이더 + −/+ 버튼, 값은 mono로 크게 | 정답 위치 표시, 근거 칩 |
| yes_no | 두 버튼 반반 | 한 줄 사실 + 근거 칩 |
| sort | 항목 옆 ↑/↓ 버튼(드래그는 지름길) | 정답 순서를 나란히 |
| before_after | 두 칸(예전/지금) 중 고르기 | 두 칸에 실제 값 |
| budget | 항목별 −/+ 로 총액 배분, 남은 금액 표시 | 실제 사용처 비율 — 정답이 아니라 "이렇게 쓰인다" |

**INVESTIGATE 허브** (M4) — 사실 공개 아래, 지금의 접힌 상자 3개를 대신한다.

```
조금 더 따져볼까요?

[원자료 2]        [AI에게 묻기]
[이 사람은?]      [관련 정책 ↗]

이 정보가 틀렸나요?
```

- 2열 타일(rounded-card, stone 헤어라인). 없는 항목은 그리지 않는다.
- 원자료·AI는 같은 화면 아래 시트로 연다(모바일 바텀 시트, 데스크톱 오른쪽 패널). URL에 `?panel=sources|ask`를 남겨 딥링크·뒤로 가기가 된다.
- `이 사람은?` — 인물 목록 시트, 각 줄이 임통으로 나가는 링크(새 탭, ↗). 통통은 이름과 역할만.
- `관련 정책 ↗` — 잼통 페이지로.
- 정정 요청은 허브 밖, 작은 텍스트 링크 — 따져볼 거리와 섞지 않는다.
- 허브는 곁가지다. `다음`은 허브를 하나도 열지 않아도 누를 수 있다.

**최종 판단 이유** (M5)

- 척도를 고른 뒤 아래에 "왜 그렇게 봤나요? (선택)" 칩 여러 개 선택. 카드마다 이유 목록(`reasonOptions`)을 둔다 — 예: 대상이 좁다, 금액이 적다, 재원이 걱정된다, 실제로 도움이 된다.
- 긍정·부정 이유를 섞어 한 목록으로, 순서는 카드마다 고정(값에 따라 바꾸지 않는다).
- 동의하지 않은 사용자는 이유도 저장하지 않는다.

**끝 화면** — 지금 그대로(무엇을 골랐는지 순서대로, 저장·공유·다음 카드, 다른 사용자 분포는 판단 뒤에만).

### 4.3 다시 판단하기 (유지)

바뀐 내용 먼저 → 판단 → 그다음 처음/지금 비교. 먼저 보여 주면 일관성 편향이 생긴다 (검토 7.3). 알림(M7)으로 들어와도 같은 순서.

### 4.4 저장한 카드 `/saved` (M6)

```
저장한 카드

청년월세 지원                [새 정보]
월세 최대 480만 원을…
2026년 신청 마감

청년미래적금                 [다시 볼 때]
…                            2026년 2차 신청 중
```

- 정렬: 새 정보 → 신청 중 → 다시 볼 때 → 나머지.
- 각 줄에서 저장 해제(확인 없이, 되돌리기 토스트 5초).
- 비었을 때: "카드 끝 화면이나 머리의 `저장`으로 모을 수 있어요."

### 4.5 내 기록 `/me` (M6)

```
내 기록

[따져본 카드 7] [저장한 카드 3] [다시 판단한 카드 2]

주제별로 따져본 카드
주거 ■■■ 3   자산 ■■ 2   교통 ■ 1   …

[판단 이력]  [저장한 카드]

내 상황 · 관심 주제            [바꾸기]
정책 평가 저장 동의 · 알림 · 기록 지키기 · 내려받기 · 지우기
```

- 주제별 막대는 무채색(ink) — 판단 데이터가 아니라 본 양이다.
- "생각이 변한 카드"는 만들지 않는다.
- 설정 묶음은 접이식 목록으로 줄여 첫 화면에 수치와 이력이 먼저 오게.

### 4.6 판단 이력 `/me/history` (M6)

설계서 65장의 목록을 시간축으로:

```
청년월세 지원
  2026.09.29  처음 본 문장   ○──────●───  대체로 신뢰
  2026.09.29  이 정책은      ─────●────  대체로 긍정
  2026.12.11  다시 판단      ───●──────  중립      ← 정책 변경 후
```

- 각 줄은 5칸 척도 위 점 하나. 같은 축끼리만 세로로 맞춘다(신뢰와 평가를 한 줄로 잇지 않는다).
- 가장 최근 = navy 실선 점, 처음 = burgundy 점선 원. 그 사이는 smoke.
- 재평가 줄 옆에 계기(정책 변경 / 90일)를 적는다.
- 차이를 숫자로 적지 않는다.

### 4.7 주제 `/topics/{topic}` (M6)

주제 이름, 한 줄 설명, 카드 목록(Hook + 신청 상태 + 내가 따져봤는지). 피드와 같은 정렬 규칙을 쓰되 이미 본 카드도 보인다. 진입점: Hook 카드의 주제 라벨, 내 기록의 주제별 막대.

### 4.8 온보딩 (M6)

생활 상황 다음에 관심 주제 선택(선택 사항, 건너뛰기 가능)을 한 단계 추가. 두 단계를 한 화면에 쌓지 않는다. 진행 표시는 막대 2칸.

### 4.9 PWA·알림 (M7)

- 설치 안내는 두 번째 카드를 끝낸 뒤 한 번, 끝 화면 아래 한 줄. 닫으면 30일 동안 다시 묻지 않는다.
- 알림 권한은 브라우저 대화상자를 바로 띄우지 않는다 — 내 기록의 알림 항목에서 사용자가 켤 때만.
- 알림 문구는 판단 값을 담지 않는다: "저장한 정책에 새 정보가 있어요", "3개월 전에 본 정책을 다시 볼까요?", "청년미래적금 신청이 3일 남았어요".
- 오프라인이면 머리에 "오프라인 — 판단은 연결되면 할 수 있어요" 한 줄, 판단 버튼은 꺼 둔다.

### 4.10 공통 상태

- 로딩: 지금의 "불러오는 중…" 문구 대신 화면 모양의 뼈대(stone 블록), 300ms 넘을 때만.
- 오류: 누른 버튼 바로 아래, ink 테두리 상자. 선택을 바꾸면 사라진다(출시 다듬기에서 적용됨).
- 빈 상태: 무엇을 하면 채워지는지 한 줄.

### 4.11 모션 (2026-10-01 점검 후 적용)

잼통 규칙 그대로 — 곡선 `cubic-bezier(0.16, 1, 0.3, 1)` 하나, 마이크로 150–250ms, 패널 250–400ms, 씬 320–420ms, 끄는 동안 전환 없음, `prefers-reduced-motion`이면 최종 상태만(뷰 전환 포함). 값은 `globals.css` 한 곳에 있다.

| 장면 | 모션 |
|---|---|
| → 보기 (스와이프·버튼·→ 키) | 카드가 제자리로 돌아와 두 번 튄다(통통, 420ms) + "통통!" 도장 → 훅 문장이 카드 화면의 훅으로 옮겨 간다(ViewTransition morph 400ms), 나머지는 250ms 교차 |
| ← 패스 (스와이프·버튼·← 키) | "패스" 도장(테두리) → 120ms 뒤 왼쪽으로 기울며 날아간다(250ms) |
| ↑ 보류 (스와이프·버튼·↑ 키) | "보류" 도장(테두리) → 120ms 뒤 위로 빠지며 작아지고 흐려진다(250ms). 저장한 카드에 모인다 |
| 다음 카드 | 뒤에 비치던 자리에서 앞자리로 올라온다(320ms), 새 뒤 카드는 아래에서 떠오른다 |
| 카드 단계·온보딩 단계 | 새 내용이 떠오른다(320ms) |
| 게임 공개 | "통!" 튀어오름, 정답 칸 ink 채움, 금액·값 막대 위 두 점 |
| 사실·허브·끝 화면·목록 | 한 줄씩 60ms 간격으로 떠오른다 |
| 척도·칩·저장 | 고르는 순간 톡(200ms) |
| 모든 버튼 | 누르는 동안 97%로 들어간다(150ms) |
| 분포·주제 막대 | 왼쪽에서 자란다(420ms) |
| 처음 → 지금 비교 | navy 점이 처음 자리에서 지금 자리로 옮겨 간다 |
| 불러오는 중 | 300ms가 넘을 때만 나타난다 |
| 오류·되돌리기 상자 | 떠오른다(250ms) |

기록 구독은 앱 전체가 하나를 나눠 쓴다(`UserDataProvider`) — 화면을 옮길 때 "불러오는 중"이 끼지 않아야 훅 morph가 짝을 찾는다.
